### 3. 基本面5维加分（专家评分阶段新增）

| 维度 | 指标 | 数据来源 |
|------|------|---------|
| 个股基本面 | PE合理性 / ROE / 资产负债率 | 腾讯行情 + 东方财富 |
| 辨识度 | 行业龙头(6类30+) / 细分领域关键词 | 名称匹配 |
| 热度 | 换手率合理区间 / 量比 / 净买入额 | 腾讯行情 |

### 4. 走势适配机制

根据大盘趋势(bull/range/bear/crash)动态调整条件优先级：
- **bull**: 趋势延续型(条件7/8)优先
- **range**: 突破回踩型(条件8)优先
- **bear/crash**: 底部反转型(条件9)优先

## 主板两阶段选股自动化（v12.24）

### 体系概览
每晚全量扫描主板，两阶段递进选股，交易日自动运行：

| 阶段 | 脚本 | 运行时间 | 作用 | 输出 |
|------|------|----------|------|------|
| 阶段1 | `stage1_night20.py` | 每日 23:00 | 全量BULL用户模式选TOP20 | `night20_latest.json` |
| 阶段2 | `stage2_auction.py` | 次日 09:27 | 竞价重排筛TOP5 | `/workspace/edge/auction_top5.json` |

- 两阶段均内置交易日校验，周末/节假日自动跳过并写日志（`/workspace/edge/auction_top5_skip.txt`）。
- 阶段1依赖核心引擎 `scan_v1224.py` + 数据 `sector_mapping.json`，路径统一在 `/workspace/stock-v1224/system`。
- 口径经回测选定：**全量 BULL 用户模式 + DUAL_COND 优先**（对比 RANGE_BULL，最近15个交易日胜率与收益均占优）。

### GitHub 调用地址（同步用）
- 仓库 URL（HTTPS，匿名只读）：`https://github.com/godsavethekingx-cloud/stock-v1224-two-stage-mainboard.git`
- 网页地址：`https://github.com/godsavethekingx-cloud/stock-v1224-two-stage-mainboard`
- 分支：`main`
- 推送：需要拥有写权限的 PAT token，一次性传入 `git push https://x-access-token:<TOKEN>@github.com/...` ，token 不落盘。详细字段见 `git_remote.json`。
- 拉取最新代码：读取 `/workspace/stock-v1224/system/run_auto.sh`，其已内置 git 同步，且不会覆盖阶段1输出 `night20_latest.json`。

### 阶段2 语法与卖出规则
- 买入：当日开盘价买入 TOP5，持股 1 天。
- 竞价分：低开/平开高配（≤0%:+15，≤1%:+10，≤2.5%:+5），大幅高开降权；剔除竞价 ≥9.5%（一字涨停买不进）。
- **止盈止损规则**（基于最近15个交易日回测优化，集中定义在 `stage2_auction.py` 的 `SELL_RULE`）：
  - 止盈：冲高至 **+10%**（或更高）落袋；**+5% 以内不手动止盈**，让盈利奔跑（低止盈会封顶收益）。
  - 止损：盘中/盘尾跌破 **-5%** 即走，不死扛。
  - 移动止盈：冲高到 +5% 后把止损上移至成本价，再涨再上移，吃冲高段超额收益。
  - 原则：用价格触发而非时间触发离场；不在次日机械收盘卖出。
- 回测说明：若按“持至次日收盘”机械卖出，仅 +0.8%/胜率50.7%；加入高止盈+5%止损后更优且对日内触发顺序不敏感。

### 回测脚本
- `backtest_two_stage.py` / `backtest_compare_mode.py`：两阶段口径对比（BULL vs RANGE_BULL）
- `backtest_horizon.py`：超短 vs 波段持股周期收益
- `backtest_tpsl.py`：止盈/止损网格优化
